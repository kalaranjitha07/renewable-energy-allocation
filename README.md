# Renewable Energy Resource Allocation System

## Project Overview
The Renewable Energy Resource Allocation System is a Java-based application designed to allocate available renewable energy resources among different consumers in a community microgrid.

The system simulates energy distribution from renewable sources such as solar and wind based on consumer requirements and available generation.

## Objectives
- To manage renewable energy generation and consumer requests.
- To allocate available energy efficiently.
- To prioritize consumer requirements during energy distribution.
- To avoid exceeding the available energy capacity.
- To provide a systematic and reliable allocation process.

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Java, Spring Boot
- **Database:** MySQL
- **Build Tool:** Maven
- **Version Control:** Git and GitHub

## Project Structure
- `frontend/` – User interface files.
- `src/` – Java backend source code.
- `database/` – Database scripts.
- `pom.xml` – Maven project configuration.
- `.gitignore` – Files excluded from Git tracking.

## Main Features
- Renewable energy generation management.
- Consumer energy request management.
- Energy allocation simulation.
- Input validation.
- Database integration.

## How to Run the Project

1. Install Java 17, Maven, and MySQL.
2. Clone or download this repository.
3. Configure the MySQL database credentials in the application configuration.
4. Open Command Prompt in the project folder.
5. Run the following command:

```bash
mvn spring-boot:run
```

6. Open the application in your browser using the configured local URL.
